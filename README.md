PriceRight
PriceRight is a marketplace seller calculator designed to estimate selling fees, total costs, profit, and profit margin.
Features
eBay fee and profit calculations
Etsy fee and profit calculations
Etsy advertising fee estimates, including Offsite Ads
Total cost and net profit calculations
Profit margin estimates
Input validation
Getting Started
Requirements
Node.js
npm
Install dependencies
npm install
Run in development mode
npm run dev
Run tests
npm test
Build for production
npm run build
Run the production server
npm start
Disclaimer
PriceRight provides estimates. Actual marketplace fees may vary depending on current platform policies, seller eligibility, category, and transaction details. Verify applicable fees with the marketplace.
